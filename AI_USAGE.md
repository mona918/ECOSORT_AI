# AI Usage

## Overview

AI-assisted development tools were used during the development of the EcoSort AI project.

The AI tools were used as development and learning assistants rather than as sources of unverified experimental results.

## How AI Was Used

AI assistance was used for:

- Understanding machine-learning and deep-learning concepts.
- Understanding transfer learning and ResNet18.
- Designing and improving data preprocessing and augmentation pipelines.
- Debugging Python and PyTorch errors.
- Debugging Streamlit application issues.
- Understanding evaluation metrics such as precision, recall and F1-score.
- Understanding confusion matrices.
- Developing scripts for model evaluation and error analysis.
- Developing Grad-CAM explainability functionality.
- Improving project documentation and README structure.
- Preparing explanations and presentation material.

## Verification of AI-Assisted Code

AI-generated suggestions were reviewed and tested locally before being included in the project.

Model training, evaluation, predictions, confusion matrices, visualizations and real-world testing results were generated by executing the project code locally.

AI-generated suggestions were not treated as experimental results unless they were independently executed and verified.

## Model and Dataset Verification

The final model performance was obtained by running the evaluation code on the held-out test dataset.

The reported results, including:

- Test accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- Real-world test performance

were based on actual project execution.

## Responsible Use

AI assistance was used to accelerate development, debugging and learning. The final implementation, experiments, results and project decisions were reviewed and verified by the project developer.
